# Merchant Churn Intelligence

AI-powered merchant behaviour analysis and retention decision support.

Upload a merchant CSV or Excel file to generate:
- Behavioural merchant segments
- Anomaly insights
- Value-based merchant prioritisation
- CSM retention playbook recommendations
- Downloadable Excel reports

Note: This application uses unsupervised behavioural analysis and business rules. It does not produce validated churn probabilities.
